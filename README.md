# IT Asset & Access Management Platform

## Overview
A security-focused web application for managing physical and digital IT assets, user access requests and role-based permissions.

## Technologies

- ASP.NET Core (.NET 8) Web API
- React
- TypeScript
- PostgreSQL
- Entity Framework Core
- JWT Authentication
- Docker
- Docker Compose

## Planned Modules

- Authentication & Authorization
- User & Role Management
- IT Asset Management
- Access Request Management
- Audit Logs
- Dashboard
